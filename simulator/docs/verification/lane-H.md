## Library / cross-question fixes
- lib/common.sh `ns_create`: waits (up to 90 s) for a Terminating namespace to disappear. Cleanup scripts delete with `--wait=false`; re-seeding right after (as `exam reset` does) otherwise created the objects in a dying namespace and they vanished (seen with q12/q78).

## Bug classes found
1. Checks that pass on untouched state (rollout complete / Available / "still exists" / "unchanged" / negative checks): q12 q13 q14 q38 q43 q78 q91 q101 q105 q106. Fixed by gating on the candidate's change.
2. Grader that could never pass: q13 jsonpath brace bug (6 points), q72 swap check (kernel shared with the Docker VM).
3. Placement checks counting Terminating pods from the previous ReplicaSet: q12 q91. Fixed with eventual checks that ignore pods with a deletionTimestamp.
4. Faults that were not actually injected or not visible: q38 (second fault in the wrong file), q105 (old Pod kept serving, maxUnavailable 0), q106 (long-lived apiserver connection).
5. Setup races with a Terminating namespace or Pod: q78 (`solo`), shared ns_create fix.
6. Solution script pitfall (harness): plain `ssh` in a stdin script eats the rest of the script; use `ssh -n` without a heredoc and no `-n` with a heredoc (`-n` drops the heredoc).
