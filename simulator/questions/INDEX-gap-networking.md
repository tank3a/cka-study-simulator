Set-building notes
- q101 and q102 both depend on cluster-scoped IngressClass objects with distinct names, so they can share a set; q101 must not run while an ingress-nginx addon default class exists.
- q98/q99 need the Gateway API addon; their namespaces are separate from q31-q33.
- Weights sum: 64. Pick a subset (about 20% of a mock set).
- Doc links come from research/official.md only. The `gateway-api.sigs.k8s.io/api-types/httproute/` page is a 404 and is not used. The kube-proxy questions link the Service concept page because no dedicated kube-proxy page is listed in official.md.
